# Engineering

O\*NET-SOC 17-0000 — Architecture and Engineering Occupations.

Hardware-adjacent and physical/technical design work: CAD, embedded
systems, electronics, 3D-printable parts — anything where the deliverable
has to work in the physical world, not just on screen.

**Typical requests:** design a 3D-printable part, wire up and program a
microcontroller, plan a small electronics build, model a mechanical part.

**Convention:** keep source files (CAD, firmware source) separate from
exported/build artifacts (STL, compiled binaries), and note the specific
hardware/tooling a project targets in its README — this category is the
least portable across machines, so being explicit about dependencies
matters most here.
