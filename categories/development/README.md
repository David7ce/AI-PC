# Development

O\*NET-SOC 15-0000 — Computer and Mathematical Occupations.

Writing, testing, debugging, and shipping software; data and ML work;
automation scripts; anything where the deliverable is code.

**Typical requests:** build a CLI tool, fix a bug, write tests, set up a
build pipeline, prototype an algorithm, automate a repetitive task.

**Convention:** each distinct project gets its own subdirectory here
(`categories/development/<project-name>/`) with its own README, rather than
mixing multiple projects' files together. A project that grows large or
needs its own git history is a candidate for graduating to its own
top-level repository, linked back from here.
