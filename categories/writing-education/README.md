# Writing & Education

O\*NET-SOC 25-0000 — Education, Training, and Library Occupations.

Documentation, tutorials, explanations, structured learning material —
anything where the deliverable teaches or explains rather than does.

**Typical requests:** write a how-to guide, explain a concept at a chosen
depth, produce onboarding docs for a project, build a study plan.

**Convention:** long-form material gets its own subdirectory; short
reference docs can live flat in this category. Prefer linking to the
authoritative source (a project's own README, upstream docs) over
duplicating content that will drift out of date here.
